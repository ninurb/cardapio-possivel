# Planejador Cardápio Possível™

Web app/PWA mobile-first, sem dependências e sem APIs pagas. Os dados ficam salvos no próprio aparelho por `localStorage`.

## Executar

Sirva a pasta em qualquer servidor estático. Exemplo:

```bash
python3 -m http.server 8080
```

Abra `http://localhost:8080`. Para instalação como aplicativo e funcionamento offline, publique em um endereço HTTPS.

## Publicação gratuita

Compatível com GitHub Pages, Cloudflare Pages, Netlify e Vercel. Não exige etapa de build.
